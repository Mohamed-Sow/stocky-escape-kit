# Reviewer Instructions

1. Install Stocky Escape Kit on the supplied review store and choose the private `shopify-test` plan. The embedded app displays this as **Stocky Review Test**.
2. Download the fictional review fixture pack from `https://stocky-escape-kit.onrender.com/review-fixtures`, then open **Files**. Choose or drag all ten `.csv` files into the staging queue. Multiple file-picker passes should accumulate files. Submit the queue once.
3. Confirm one migration run is created with **10 files**, **38 parsed rows**, **33 warnings**, and **1 expected failed file** (`stocky-malformed-unclosed-quote.csv`). The warning total includes the deliberately duplicated proprietary header in the fixture pack. Every file, including the malformed file, must have a raw archive download.
4. Select the new run and choose **Sync Shopify and audit**. The current supplied review-store catalog reports **17 products, 26 variants, 26 inventory items, and 2 locations**. If that catalog changes, record the live counts instead of treating a count difference as an incomplete sync. The app deliberately does not claim an inventory-level count from a truncated nested connection.
5. Open **Findings**. Confirm the selected run includes the deliberate duplicate-header, column-count, and malformed-file unknown-column findings. The current supplied review-store catalog produces **61 findings**; the local canonical mock catalog produces **57 regression-test findings**, so the exact live total can change with the store catalog. Test the server-backed severity and category filters, search for a SKU, move between result pages when present, and review grouped source rows plus the recommended action.
6. Open **Exports**. Download the parsed archive, complete audit findings, supplier evidence, and migration checklist CSV files. Each must be non-empty and scoped to the selected run. The audit findings CSV must include parser failures, SKU/catalog gaps, supplier evidence, and open-purchase-order follow-up—not only SKU issues.
7. Download **Migration package**. Confirm the ZIP contains all ten original files under `source/`, the same four generated CSV reports, and `manifest.json`; each manifest entry includes its kind, filename, byte count, and SHA-256 checksum.
8. Return to **Files**, select an older run if available, and confirm its files, findings, and export history remain isolated from the canonical run.
9. Open **Settings** and inspect the retention explanation. Do not execute the reset on the review store.

Historical Stocky purchase orders are preserved and reviewed as evidence. They are not imported into Shopify. All Shopify access in this workflow is read-only and uses the GraphQL Admin API.
